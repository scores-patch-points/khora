# EO clause: English reads like Greek

*Standing finding, 2026-10-09. One sentence: English has no case-ending, but
**position IS its case** — so the same clause shape the Greek seam emits
({verb, subject, object, dative}, each argument {head, at, case, cell}) is
English's too, and the cube parses both identically.*

## The move

The user's directive was the unlock the night was circling: "bring it from SVO
to EO so it can fit in the cube and we can parse it just like greek." The
English seam had been emitting bare string tokens (subject="Darcy",
object=null). The Greek seam emits EO clauses — a verb staging its arguments,
each in a role-seat cell. English answers the same shape, because the S-V-O
seat IS the case-marking:

| seat | case | cell |
|---|---|---|
| before the verb | Nom | `agt` |
| after the verb | Acc | `pat` |
| to/for-headed | Dat | `rcv` (the raised Field cell) |

An empty object is now a **typed empty slot** — a gap the cube can read —
never an absence. This is the internal answer to the English object starve:
the object was never missing, the SEAT was untyped.

## Why it was discoverable

Structure vs content, applied to the seam itself. The English POS prior is
content (a wordlist); English word-order is structure (position). The seam
that read content refused `darcy` (no prior entry); the seam that reads
position-classifies it — exactly as Greek case-endings classify any form.
Once the seat is positional, the object is always seated, even when empty,
and the whole cube — the scene kinds, the identity seats, the toys — parses
English with the same machinery as Greek.
