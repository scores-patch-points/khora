# THE-SUBSTRATE

*The name for the pipeline guides in khora. Canonical rule, 2026-10-08: janus
holds the RULES of how to read (linguistics priors — pos, case, lemma, nominal
endings — the kinds, the nomos). Khora is the perceiver/engine; anything in it
that approximates a pipeline guide — a document that orchestrates how a reading
flows through the folds toward the mouth — is called the **substrate**: the
ground the folds run on, never the rulebook itself. A substrate tells the run
how the organs are to be wired; the rules behind each wiring live in janus.*

## The rule

- Janus = the reading rules (priors one home: `janus/priors/`; `priors-have-one-home-janus`).
- Khora = the perceiver. A document in khora that would otherwise be fancied a
  "pipeline guide" is named **substrate**. The name is the class, not a
  decoration: a substrate is the fixed layer the folds run over.
- No new "*PIPELINE.md*" names in khora. The pipeline-guide class is the
  substrate class. A document that reads like a pipeline guide is renamed or
  named substrate; a genuinely new guide is born `THE-*-SUBSTRATE.md`.

## The registry (living)

- **THE-READING-SUBSTRATE.md** — the reading pipeline (formerly *PIPELINE*),

- **THE-ENZYME-SUBSTRATE.md** — the enzyme pipeline, the organs as the body of

- **THE-STIGMERGIC-SUBSTRATE.md** — the stigmergic pipeline, deposition and
  evaporation as the two-handed weave of reading.
- **3.0/the-substrate-the-tapestry-is-the-holograph.md** — the bound-EOT canon:
  coreference by activation *during* the read (never after), surprise carried
  per clause (admit, the cloth revised by the reading), and the khora → janus →
  penelope pipeline flowing the bound EOT into kinds and the record. The answer
  to "what is the tapestry in khora" is the cloth — the holograph — and the
  substrate is its guide.

## What is NOT a substrate

- `janus/priors/*` — the rules themselves (never renamed; they are the ones held).
- The hearing/run: the future active voice; a thing in motion is hearing.
- `THE-SPINE.md`, `THE-WHEEL.md`, `THE-HOLOGRAPH.md` — constitution/math/canons,
  not run-guides ("*SPINE" and "*WHEEL" name the architecture; "*PIPELINE"/run-guides are substrate).
- Operational runbooks (e.g. `SCREENSHOT-PIPELINE.md`) — how-to for a specific
  organ is a runbook, not the substrate. Debatable; erred toward not renaming.
