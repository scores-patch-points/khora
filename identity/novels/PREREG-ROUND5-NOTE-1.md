# NOTE 1 to PREREG-ROUND5, 2026-11-17, before any learner is trained: a UNIVERSAL learner with learned attention, run on two unrelated tasks
The user's brief: learn how to learn in a universal way, and learn how attention (the signal) should attend. Attention is read as the pheromone idea of the pharos plan: a signal is attended in proportion to the net saving it has produced, and its trail evaporates when it stops paying.
## attend.mjs: one learner, no task code in it
Input: rows { x: evidence vector, y: 0/1, g: group }, and `channels`: which named channel each feature belongs to. Model: logistic regression, score = b + sum_j gate[channel(j)] * w_j * x_j, features standardised on the training groups, Adam (lr 0.05, 150 epochs), L2.
LEARNED LEARNING: the L2 strength is chosen from {0.001, 0.01, 0.1} by validation loss on held-out training GROUPS (logged). LEARNED ATTENTION (3 rounds, declared): hold out a quarter of the training groups (by hash of the group); fit; the CREDIT of a channel = validation log-loss with the channel zeroed minus validation log-loss with it present
(its net saving); pheromone tau_c <- 0.5 * tau_c + credit_c (evaporation rate 0.5, declared); a channel keeps its gate (1) when tau_c exceeds 1.4826 x MAD of the round's credits (its own relative unit), else the gate is 0 (evaporated) and it stays out of later rounds; refit on all training groups with the final gates. No dial is tuned on any task.
## Task 1: choosing the answer (this round's QA data, leave-one-book-out). Channels: the feature groups of featurize.mjs (candidate form, role, frequency, sentence/retrieval, overlap, position, graph-act, and the question-type crosses).
## Task 2: record identity (Open Library editions, identity/books/raw, leave-one-SUBJECT-out over the 10 subjects). Decision = a pair of edition records, y = same work. One pair per work with >= 2 editions (seeded), an equal number of different-work pairs (seeded).
Channels = the 11 relations of books.py (title_tok, author, language, translated_from, publisher, year, pages, format, class, subject, series); per relation the features agree, disagree, missing (and title-token Jaccard, year-gap closeness as extra features of their channels).
## Hypotheses
A1 (QA): the gated learner's LOBO F1 exceeds the ungated learner's (cluster interval excludes 0): attention pays. A2 (identity): the gated learner's LOSO AUC is within 0.005 of the ungated one's while keeping fewer channels. A3: the attended channel sets differ between the tasks (attention is learned, not built in).
A4 (universality): with the same code and no per-task tuning, the identity learner's LOSO AUC exceeds the best single channel's. Also reported: the learning curve of each task and the L2 chosen.
Predictions, so they can fail: A1 fails (little data; gating is noise); A2 holds; A3 holds; A4 holds.
