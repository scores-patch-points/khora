# PREREG round 10: try to FALSIFY that the canonical pronoun bindings are correct (English, our books; gold-free) (2026-11-17, before the script is written)
The canonical read binds about 98% of he/she-class pronouns (presence rung, chosen dials). Binding is not correctness. A GOLD-FREE falsifier: a referent that is bound to both a masculine pronoun (he, him, his, himself) and a feminine one (she, her, hers, herself) has at least one wrong binding (assuming a referent has one grammatical gender in a book). LOWER BOUND on wrong bindings per book = sum over referents of min(number of masculine, number of feminine bindings). Lower-bound error rate = that / bound pronouns.
NULL: the same bound referents permuted across the same pronoun occurrences (200 permutations per book), preserving how often each referent is bound.
Data: the bindings of the 49 read books (tracked-best = chosen dials; tracked = the control dials of rounds 4-8), no test split needed (no tuning).
Hypotheses (each can fail): F1: the observed lower-bound error rate with the chosen dials is below the null's (book-cluster 95% interval of null minus observed excludes 0): the bindings carry gender information beyond chance. F2: the lower-bound error rate with the chosen dials is above 0 on most books (the "98% bound" claim is falsified as "98% right"). F3: the chosen dials have a HIGHER lower-bound error rate than the control dials (binding everything costs correctness).
Predictions so they can fail: F1 holds; F2 holds with a lower bound between 3% and 15%; F3 holds. A lower bound is not the error rate: wrong bindings between referents of the same gender are invisible to this test, so the true error is higher.
Gold test (English): eval/referents/pronoun-golden.mjs on the UD English GUM slices that were never looked at while the rule was built (C and D) with the chosen presence dials, reported separately after this.
