# PREREG round 6: wormholes (identity links between far-apart places), tested on questions that name no character (2026-11-17, before any wormhole code, before any round-6 book is read)
Measured on seen books (262 questions that name a referent): the answer's sentence is a mention of the named referent 66% of the time, within 3 sentences 86%, within 10 sentences 92%: the cast already acts as a set of wormholes (a referent links all its mentions anywhere in the book).
The gaps: 94 of 362 questions (26%) name no referent, so there is no mouth to enter; main characters have hundreds of mouths; wordings differ. A WORMHOLE here is an identity claim between two or more places of a text: all of them are the same thing; entering any mouth gives all the others.
## Wormhole for descriptions (wormhole.mjs)
A description = a clause argument starting with a determiner (the / this / that / these / those) that is not a cast mention; its head = its last word before "of" or the span end. Each occurrence is bound to a cast referent by decayed presence (the tracker's own dials: window 4, boost 2, floor 2, margin 0.3; unbound if it clears no floor/margin).
IDENTITY TEST (falsification first, no hand-set threshold): a head h is linked to its most frequent referent r* only if all its bound occurrences are not distinguishable from one referent: the share of bound occurrences that go to r* must exceed what random presence-binding gives, by z >= sqrt(2 ln H) (H = distinct heads tested in the book; null = binding each occurrence to a uniformly random present referent, 200 draws), with at least 3 bound occurrences; otherwise a typed gap (too_few / not_concentrated). An admitted link makes EVERY occurrence of "the h" (bound or not) a mention of r*, and the question word h an entry to r*.
Silver check: appositive witnesses in the text ("<mention>, the h", "the h, <mention>", "<mention> was/is the h" inside one sentence) give witnessed (h, referent) pairs; precision = admitted links whose witnessed referent is r*; compared with the unfiltered presence binding of the same heads.
## Retrieval test (wormhole-eval.mjs): the referent cut of round 4 (hop 0 / hop 1, tracked graph, dmd cut) with the wormhole mouths added, entries = named referents plus referents entered through a question word that is an admitted head.
## Data
DEVELOP: the 34 read books (all seen). TEST: 8 NEVER-read books from a new, declared size window: test-split Gutenberg books with 8,000 <= story_word_count < 15,000, excluding every book already used, shuffled with Python random.Random('nqa-round6-20261117') over document_ids sorted; the first 8 that pass AMEND-1b's integrity rule (15% token-count band). Questions filtered by Q1-Q5 (unchanged) and opened only after FREEZE-ROUND6.md.
## Hypotheses (can fail)
W1: admitted links beat the unfiltered presence binding in silver precision (over books with at least one witnessed head; sign test or interval excludes 0). W2: among questions that name no referent, the wormhole entry gives an entry to some (share > 0), and where it does the gold sentence is inside the cut more often than inside plain BM25's top-k of the SAME size (book-cluster interval excludes 0).
W3: adding wormhole mouths raises gold-inside-cut for questions that already name a referent (interval excludes 0). Not tested: kinds, setup-payoff, wording wormholes (paraphrase), answer F1.
Predictions so they can fail: W1 holds weakly (silver sparse: few appositives); W2: entries for 15-35% of the no-name questions, gold inside the cut above chance but NOT above BM25 of equal size (descriptions cover too few); W3 fails (named-referent coverage is already high).
