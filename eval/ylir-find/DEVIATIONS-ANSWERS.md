# Deviations from the stamped answer protocol (answers-dev.json, STAMP-ANSWERS.txt)

1. WHOLE WORDS, NOT SUBSTRINGS (2026-11-24, after the third arm). The stamped rule said "right if the answer contains one of `accept` (case-insensitive substring)". The third arm's one "right" ("Who is Jim Hawkins?" -> "THE GARRISON IN THE STOCKADE", a chapter title) matched the accepted word "son" inside "garrison": a flaw of the rule, not a right answer. From then on the judge compares whole words, for every arm (`rejudge.mjs` rescored all of them the same way). The accept lists are unchanged. "Dr." for Van Helsing stays WRONG under the lists as stamped, although it is arguably a right description (the list has "doctor", not "Dr."): the lists are not adjusted after seeing answers.
2. THE ARMS are one protocol run four times on the same DEV questions (the questions were already scored for document finding): exact verb only; with the relation stand-in; with the relation stand-in and a first identity tier; with the identity tier tightened after its failures. Each change was made after looking at the previous arm's answers, so no arm after the first is a clean test; all are DEV, EXPLORATORY. The fresh set is untouched.
