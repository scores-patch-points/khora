Prompted, and audited the same system under different prompts; every reply shows where it came from

No language model runs here. When a prompt is on, the system computes each reply from the prompt's own sentences, and the card under the reply names the sentence, the prompt (by sha256), and the command that replays it. “As Claude” means “answered from the words of a Claude system prompt.” It is not Claude.

The experiment

Five checks, each of which can fail. DIFFERENCE: the same question under different prompts gets different replies. INVARIANCE: a question a prompt cannot speak to gets the same reply under every prompt. DETERMINISM: the same prompt asked twice gives the same bytes. CAUSE: cutting out the sentence a reply came from changes the reply. COVERAGE: where a fixture prompt says something, the system used it. It takes about 30 seconds, then every cell of the table opens its own full audit.
