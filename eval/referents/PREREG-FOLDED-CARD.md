## What is built

`native/adapters/text/folded-card.js`: `renderCard(entry, referentId, { asOf, forWhom, question, window, stated, declension, swap })` over a ledger entry (`referents: true`), returning
`{ text, question, messages, map, left, size, sha256, frame, swapped }`.
- **text**: plain prose, English wrapper and the text's own language in the quotations: (1) the frame (for whom, about whom, as read up to which point); (2) the names, every surface the ledger folded to the referent, how often, and the giver of each fold; (3) the appearances, each a sentence with the stretch marked and one sentence either side; (4) the edges whose end is the referent, as plain sentences with polarity as fact; (5) the pronoun bindings that landed on it; (6) the rows a giver states about it, supplied by the caller; (7) what the card does not hold, as fact. Each selectable item carries an ordinal **local to the card**.
- **map** (private; never in `text`): each ordinal to its fold address (ledger span ids, referent id, edge id, section). **messages**: `[{ role: "system", content: text }, { role: "user", content: question }]`, the question last and verbatim.
- **Size by the question and the window.** The question kind (identity, contradiction, gap, derivation, free) orders what is spent first; `window` is the caller's loaded window in characters (never a default here). Nothing is truncated silently: each omission is a count in the card and in `left`; if the mandatory parts (frame, names, the not-held statements) do not fit, it returns `fits: false` and does not shrink them.
- **Name-swap**: with `swap: { <base name>: <invented base name> }` every surface of the referent is replaced consistently, the case forms generated by the same declension table that folded them, and the old stems that remain anywhere in the text are counted (`swapped.leaks`).
- Behind an off-by-default option: `readWith(text, { referents: true, card: true })` attaches a **non-enumerable** `entry.renderCard`; off, the entry is byte-identical.
- The kinship rows are an INPUT (`stated`); the renderer asks no giver. With none supplied, the card states that as a fact.

## Bars (mechanical; decided now)

- **K1 no address.** The card text contains no `ref_`, `spn_`, `evt_`, `edg_`, `ref:auto:` or `material#` string and no 16-hex-digit run; the same holds for the swapped card.
- **K2 Gary.** `makeGary({}).check(messages, { material: <appearances shown> })` returns no finding of severity `strike` or `refuse`, on every card the report renders; every `flag` is reported with its clause. On the Russian excerpt I expect no flag from the wrapper's own prose; a flag from quoted English text is possible and is reported, not hidden.
- **K3 size, never silently.** With a window, `size.chars <= window` or `fits: false`; for every section, items shown + `left` = items available; each non-zero `left` is stated in the card as a count.
- **K4 the private map.** Every ordinal in the text is in the map exactly once and the map has no ordinal that is not in the text; every address in the map resolves in the ledger (the span, the referent, the edge exist); no address string occurs in the text.
- **K5 name-swap.** The swapped card has the same lines, the same ordinals and the same map as the plain card; no token of the referent's old forms remains (`leaks: 0` on the Russian excerpt's Natasha and Pierre, or the leaked words named); the invented name's case forms follow the fold (a form that `declension.js` reaches from the invented base); the hash differs.
- **K6 determinism.** The same inputs give the same text and the same sha256.
- **K7 off.** Option off: the entry is byte-identical to main's (the JSON, `ms` zeroed) on the fixtures and the excerpt; the reader's import graph stays free of `node:` (the page-safety test); the CI workflow's own steps pass.

## Reported, not barred
Card sizes (characters, lines, an estimate of tokens at the Gary counter's four characters to a token) by question kind and referent, with and without a window; the number of Gary flags; `left` by section.

## Decision rule and what is not claimed
If K1 to K7 hold, the module, its tests and the report are offered as a PR (additive). A failed bar is a finding and is reported with the card that failed it. Not claimed: that a card of any size is enough for a model to decide an open case; that the name-swap rules out the model's memory of the plot (it rules out the name); that Gary's rules are optimal; anything about a model, which is not called. The controls of THE-FOLDED-CARD.md section 5 that need a model (invariance of answers, ablation, wrong card, plain baseline) are claude-ring's, after this.
